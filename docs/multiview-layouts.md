# 多屏直播 — 布局方案设计

> 对应 TODO.md 功能 #1「多屏直播」。本文档只记录布局相关的细化设计，其余（多播放器实例管理、弹幕后端多实例改造等）见 TODO。
>
> 结论日期：2026-08-16

## 一、设计原则

1. **手动选布局**：用户从布局选择器里手动挑选横版/竖版布局；窗口拉伸变形时**不**自动切换布局，格子随窗口自然缩放。
2. **横竖分开定义**：横版面向 16:9 横屏直播画面（斗鱼/虎牙/B 站），竖版面向竖屏窗口/竖屏画面（抖音），两者是独立档位，不是同一布局的转置。
3. **性能上限**：同屏最多 4 路解码（WebView2 环境下 4 路以内较稳）。不做 6/9 宫格。
4. **空格子**：未分配房间的格子显示占位 UI（“点击添加房间 / 从关注栏拖入”），不塌缩。

## 二、布局总览

| 布局 | 格数 | 方向 | CSS Grid 模板（列 / 行） |
|---|---|---|---|
| 双屏 `SPLIT_2` | 2 | 横版 | `grid-template-columns: 1fr 1fr; grid-template-rows: 1fr` |
| 四宫格 `GRID_4` | 4 | 横版 | `grid-template-columns: 1fr 1fr; grid-template-rows: 1fr 1fr` |
| 主副 1+3 `PIPS_1_3` | 4 | 横版 | `grid-template-columns: 1.9fr 1fr; grid-template-rows: 1fr 1fr 1fr`（大格 `grid-row: 1 / span 3`） |
| 竖双屏 `STACK_2` | 2 | 竖版 | `grid-template-columns: 1fr; grid-template-rows: 1fr 1fr` |
| 竖三屏 `STACK_3` | 3 | 竖版 | `grid-template-columns: 1fr; grid-template-rows: 1fr 1fr 1fr` |
| 竖四屏 `STACK_4` | 4 | 竖版 | `grid-template-columns: 1fr; grid-template-rows: 1fr 1fr 1fr 1fr` |

> 1+3 的大格宽 ≈ 65%（1.9 : 1 ≈ 65 : 35）。

## 三、横版布局图示

格子编号为展示顺序（第 1 格 = 左上 / 主格）。

### 3.1 双屏 `SPLIT_2`（2 格）

```
┌──────────────────────────────┬──────────────────────────────┐
│                              │                              │
│                              │                              │
│              1               │              2               │
│                              │                              │
│                              │                              │
│                              │                              │
└──────────────────────────────┴──────────────────────────────┘
          ←──────────── 约 50% ────────────→
```

- 用途：两路原画同播（对画质要求高的场景）。
- 竖屏画面在该格内 `contain` 居中，左右留黑边。

### 3.2 四宫格 `GRID_4`（4 格）

```
┌──────────────┬──────────────┐
│              │              │
│      1       │      2       │
│              │              │
├──────────────┼──────────────┤
│              │              │
│      3       │      4       │
│              │              │
└──────────────┴──────────────┘
```

- 用途：通用 4 路同播。

### 3.3 主副 1+3 `PIPS_1_3`（4 格）

```
┌──────────────────────────────┬──────────────┐
│                              │      2       │
│                              ├──────────────┤
│              1               │              │
│          (大格 · 焦点)        │      3       │
│                              │              │
│                              ├──────────────┤
│                              │      4       │
└──────────────────────────────┴──────────────┘
          ←────── 约 65% ──────→ ←── 约 35% ──→
```

- 大格 = 焦点格，默认承载当前有声的房间，点击任意小格可与该小格交换槽位。
- 用途：主看一路 + 侧看三路。音频策略（待定项）的载体。
- 大格与小格互换按“槽位交换”处理（点击小格 → 该房间移入大格，原大格房间回到小格），不重建播放器实例、只移动 DOM 容器或交换流地址。
- 全屏任意一格（双击或格内控制栏全屏按钮）时，布局容器退化为单格全屏形态。

## 五、交互规则（布局相关）

1. **选择布局**：多屏模式工具条 / 设置菜单内提供 6 档布局选择器，每档展示缩略示意（同本文章节三/四的图形）；按钮按格数由少到多、从左到右排列。
2. **槽位填充**：布局切换时按格子编号顺序尽量保留已有房间（例：4 宫格 → 双屏，保留 1、2 号格的房间，3、4 号格的房间被移出；反之新出现的格子显示占位）。
3. **焦点格**：仅 1+3 有焦点格概念，焦点即大格；其他布局无焦点，音频策略待定后统一。
4. **单格操作**：每格右上角悬浮关闭按钮（X）关闭该格房间；支持从关注栏拖入房间到指定格（拖拽分配，二期实现）。
5. **单格全屏**：每格提供“全屏”按钮（CSS 全屏，见 `player.css` 现有 `cssFullscreen` 相关逻辑），全屏时其余格子隐藏，退出后恢复原布局。
6. **滚动音量**：TODO #2 的滚轮调音量按格生效（悬停在哪个格，调哪个格的音量）。

## 七、非目标（明确不做）

- 六宫格 / 九宫格：WebView2 多路软/硬解性能不可靠，暂不做。
- 自定义拖拽分屏（自由调整行列比例）：复杂度高，放二期以后。
- 窗口横竖自动转置：布局手动选择，不随容器宽高比自动切换。
- 竖屏内容并排（1×3 列）布局：竖版需求用上下堆叠档位覆盖。

## 九、实现注意（从现有代码得出）

- `web/src/components/player/MainPlayer.tsx`（~1500 行）承载了单实例的全部逻辑（流获取、xgplayer 挂载、弹幕后端、顶栏、窗口控制）。多屏需要拆出**可复用单格播放器组件**（如 `PlayerCell`）+ **多实例网格容器**（如 `MultiViewGrid`）。
- `web/src/components/player/player.css` 的 `player-layout / main-content / player-container / video-container` 均按单容器写死；多屏需新增 `.multiview-grid` 系列样式（CSS grid + `aspect-ratio` 不强制，随窗口拉伸）。
- Rust 侧弹幕后端当前为全局单房间策略（`stopAllDanmakuBackends` 在每次切换前全停），多屏需改造为**按房间多实例**：`start_*_danmaku_listener`/`stop_*` 需支持并发多房间，事件按 `room_id` 分发。
- 各平台代理（`ensureProxyStarted`、斗鱼/虎牙 proxy）当前同样按单会话设计，多实例同平台并存需验证。
- 弹幕渲染（`danmuOverlay`）目前是“单 overlay 单房间”，多屏要么每格独立 overlay，要么共层分色；建议**每格独立 overlay**，简单且隔离故障。
- 窗口置顶（PlayerUiProvider `isAlwaysOnTop`）与单格 CSS 全屏的层级关系需理顺（置顶是窗口级，全屏是格级）。
